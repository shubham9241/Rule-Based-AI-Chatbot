# Rule-Based-AI-Chatbot
A simple Python-based rule-based chatbot that responds to user queries using predefined rules and pattern matching.

## About

This project is a simple rule-based chatbot developed using Python.
It responds to user messages by matching them with predefined
rules and patterns.

## Features

- Responds to greetings
- Answers basic questions
- Provides help
- Handles thank-you messages
- Supports exit commands
- Handles unknown queries

## Technologies Used

- Python
- If-Else Statements
- String Processing
- Pattern Matching

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code or Terminal.
4. Run:

```bash
python chatbot.py
